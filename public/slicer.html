Post-processing script

            

          

          
            en_ucuz_slicer.py indir
          
          
    
            
  1. Dosyayı bilgisayarınıza kaydedin (ör. C:\EnUcuz\en_ucuz_slicer.py).
    2. 
            
  2. Slicer'da Print Settings → Output options → Post-processing scripts kutusuna
              dosyanın tam yolunu yapıştırın.
    3. 
            
  3. Dilimleyip kaydedin — bildirim otomatik gelir.
    4. 
          


          

            Python yok mu? (Windows)
            
Betik Python 3 ile çalışır. Kurulu değilse
              python.org'dan
              kurun ve "Add python.exe to PATH" seçeneğini işaretleyin.
              Ardından kutuya şunu yazın:

            
python "C:\EnUcuz\en_ucuz_slicer.py"

            
Kendi .exe dosyanızı üretmek isterseniz:

            
pip install pyinstaller
pyinstaller --onefile --noconsole en_ucuz_slicer.py

            
--noconsole ile derlerseniz --test çıktısını
              görmezsiniz; bildirimler yine çalışır.

          


          

            Kurulumu doğrula
            
Terminalde şunu çalıştırın:

            
python en_ucuz_slicer.py --test

            
API'ye ulaşırsa bir test bildirimi gösterir. Bağlantı yoksa
              SONUÇ: API'ye ulaşılamadı yazar — dilimleme yine etkilenmez.

          

        

      

    


    

      
Nasıl çalışır

      

        

          1
          Dilimleme biter
          Slicer gramajı ve malzeme türünü G-Code'a yazar.
        

        

          2
          Eklenti okur
          Yalnızca filament used [g], filament_type ve renk.
        

        

          3
          API sorgular
          68 mağazadaki stoklu en ucuz makara, 1,5 sn zaman aşımıyla.
        

        

          4
          Bildirim gelir
          “Bu baskı 340 g PLA gerektiriyor. En ucuz ₺463,68 ile Porima 3D'de.”
        

      

    


    

      
Gizlilik ve dürüstlük

      
    
        
  • Ne gönderilir: yalnızca malzeme türü (PLA/PETG…), gramaj ve kaynak etiketi
          (cura, bambu…). Renk isteğe bağlı.
    • 
        
  • Ne gönderilmez: dosya adı, model içeriği, G-Code, IP dışında hiçbir kişisel veri.
    • 
        
  • G-Code değiştirilmez: post-processor dosyayı yalnızca okur; içeriğine
          dokunmaz.
    • 
        
  • Dilimleme asla yavaşlamaz: ağ isteği ve bildirim ayrı süreçte çalışır;
          post-processor milisaniyeler içinde döner.
    • 
        
  • Bağlantı yoksa sessizdir: API'ye ulaşılamazsa hiçbir şey gösterilmez,
          dilimleme kesintiye uğramaz.
    • 
        
  • Uydurma fiyat yok: stokta uygun filament yoksa “bulunamadı” denir,
          sahte fiyat gösterilmez.
    • 
      

    


    

      
API (kendi entegrasyonunuz için)

      
Herkese açık, CORS destekli, 60 sn önbellekli.

      
GET /api/embed/oner?malzeme=PLA&gramaj=340&renk=Siyah&kaynak=cura

{
  "status": "success",
  "talep": { "malzeme": "PLA", "gramaj": 340, "renk": "Siyah" },
  "enUcuz": {
    "urunAdi": "Porima xPLA Filament Siyah 1kg",
    "magaza": "Porima 3D",
    "fiyat": 463.68,
    "parcaBasiMaliyet": 157.65,
    "makaradanCikanAdet": 2,
    "stok": true,
    "yonlendirmeLinki": "https://baskihesap.tech/yonlendir?urunId=4&kaynak=cura"
  },
  "bildirimMetni": "Bu baskı 340 g Siyah PLA gerektiriyor. …"
}

      
Parametreler: malzeme · gramaj (zorunlu) ·
        renk · kaynak. Gramaj yoksa 400,
        stokta ürün yoksa status:"bulunamadi" döner.
